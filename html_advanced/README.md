# HTML advanced - Headphone company

![Headphone company preview](html_advanced/images/preview.svg)

This project builds, from scratch, the webpage of a headphone company from a Figma designer file.
It focuses only on the HTML structure: no CSS and no styling, just pure semantic HTML.
The page is built step by step, one section per task: header, banner, quote, videos, membership, FAQ and footer.
Styling will come in the next projects, on top of this semantic skeleton.
